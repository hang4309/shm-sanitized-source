# 中文阅读与复现说明

这是保留 Fable5 重构版本的结构健康监测半成品：Python 采集文件，Spring Boot / MyBatis 接收并存入 MySQL，Vue 查询并绘图。公开版补充工程说明和合成演示，方便代码审阅、求职展示和面试复现。

[英文首页](../README.md) · [完整启动顺序](runbook.md) · [架构与可讨论问题](architecture.md) · [实测范围](validation.md)

## 已有能力与边界

- 文件增量读取、断点状态、来源文件/行号追踪、有限次数 HTTP 重试。
- 统一读数表与模块映射，latest/history 接口，共用监测页和 SVG 曲线。
- 六个模块是同一读数模型的分类视图，不能包装成六套物理算法。
- 主值来自文件的强度/能量列；波长是辅助参考。没有完成物理标定，不能把演示值说成真实应变、位移或应力。
- 预测和裂缝页面仍是“待接入”壳；没有生产验收结论。

## 最快复现

在仓库根目录运行：

```powershell
python tools/demo/generate_synthetic.py
python -m unittest discover -s tools/demo -p "test_*.py" -v
node --test tools/demo/test_chart.mjs
```

全部输入均明确标为 **SYNTHETIC（人工合成）**，不是客户或设备数据。采集器测试使用临时本机 HTTP 录制服务，证明解析、上传载荷和重启续传等局部行为；这不等于 Java/MySQL 全链路通过。

完整应用按 [runbook](runbook.md) 依次启动：独立演示数据库 → 后端 → 生成六条合成记录 → 原采集器 → API 校验 → 前端。界面选择“监测数据 → 应变”，手动时间窗设为 `2025-01-01 00:00:00` 至 `2025-01-01 00:00:05`，应有六点，主值从 10.00 到 11.25。其它模块为空是预期行为。
